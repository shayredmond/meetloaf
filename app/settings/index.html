Link routing

When you click a meet.google.com link, MeetLoaf can intercept it instead of opening Meet in your browser. The Firefox extension handles links inside Firefox; pair it with Velja for links from Slack, Mail, Calendar, etc.

  1. Click Open extensions — your browser opens chrome://extensions.
  2. Toggle Developer mode (top-right of the page).
  3. Click Show folder here — Finder opens with the extension folder selected.
  4. Drag the extension-chrome folder onto the extensions page (or use Load unpacked and select it).
